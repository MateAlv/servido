# Evaluación y aprobación

## Condiciones (hay que cumplir todas)

- **Asistencia a prácticas**: mínimo 75 %, presencial o remota. La asistencia a la **defensa final es obligatoria**.
- **Asistencia a teóricas**: mínimo 50 % (se recomienda 75 % para no depender de notas muy altas en el resto).
- **Mini-exámenes semanales**: aprobar 2 de cada 3, cada uno con 60 % de respuestas correctas.
- **Trabajo práctico grupal**: seguimiento continuo, entregas incrementales y defensa final. **La nota es individual.**
- **FIUBA Talk**: dar una charla en equipo sobre un tema de la materia.
- **Puntaje final mayor a 6.**

## Fórmula

```text
Puntaje = 0,1·AT + 0,15·Parcialitos + 0,4·TP + 0,35·FT + p
```

| Término | Significado |
| --- | --- |
| AT | Nota por asistencia a teóricas: < 50 % → 0 · 50–75 % → 5 · 75–80 % → 8 · > 80 % → 10 |
| Parcialitos | Promedio de los mini-exámenes (un ausente cuenta como 0) |
| TP | Nota del trabajo práctico |
| FT | Nota de la FIUBA Talk |
| p | Participación en clase: +0,1 por participación, máximo 1 |

## Implicancias para el equipo

- El TP es el 40 % del puntaje y su nota es individual: cada integrante tiene que poder explicar lo que se entregó, incluido el código generado con IA.
- La defensa final es obligatoria para todos.
